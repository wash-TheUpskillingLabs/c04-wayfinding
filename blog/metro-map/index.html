      Our first prototype is a Metro map

      An events list tells you what’s on. A map tells you whether you can get there. So the region put every library on the Metro.

      The Wayfinding pod, Nov 6, 2026. A two-minute read.

      The question behind the question

      An events page answers “what’s on?”

      That’s rarely the question a person actually has at six on a Tuesday. The real one sounds more like: is there something near me, and can I get there after work?

      That’s a wayfinding question. And Greater Washington already has a wayfinding system almost everyone here knows by heart: the Metro.

      A map people already know how to read

      So the first prototype of literal wayfinding on the Greater Washington OLOS fork borrows it. Every public library branch across DC, Arlington, Alexandria, Falls Church and Montgomery, Prince George’s and Fairfax counties sits on the Metrorail lines, drawn alike, because the region is one place.

      A branch with a session coming up is filled, ringed and linked to it. Type a ZIP code, a neighborhood or a library, and the map moves your point, sorts the sessions by distance and opens the nearest one. Open a library and it lights the closest station and names the walk, when it’s fifteen minutes or less.

      Nobody has to learn the map. They learned it on the Red Line.

      An empty library is an invitation

      Most event maps only show where something is happening. This one shows every branch, including the ones with nothing scheduled.

      Tap an empty one and it doesn’t say “no events.” It asks whether you’d like to coordinate a workshop for your neighborhood. For now that’s an email; a form can follow once we know people use it.

      An empty slot is an absence on most sites. Here it’s a door.

      Built to be quiet

      The map is drawn from real geography with no map tiles and no tracking. What you type is never stored. The site counts searches per day by area, anonymously, so the region can see which neighborhoods want workshops. That’s a logged exception to The Labs’ rule against activity tracking, and it’s said plainly in the privacy notice.

      The list of sessions stays the way in for keyboards and screen readers; the map adds where. It draws itself once when it comes into view, and with reduced motion it’s simply there.

      What it can’t tell us yet

      A map can show a library is close. It can’t make someone walk in.

      The case studies keep telling us that people stay for people, and that a nudge only works with a person behind it. So the questions this prototype hands to the pod:

      • How might the map show who’ll be there, not just where?
      • How might someone who came once see the next session near them, without being chased?
      • How might a neighbor’s offer to host turn into a real session at their branch?

      Like every prototype this Cycle, it goes in front of three real people next. If you try it, tell us what you looked for first.

      Try it

      It’s live on the region’s fork of OLOS, a prototype we’re building as we use it. Things will change, and the data may be reset.
