The map is drawn from real geography with no map tiles and no tracking. What you type is never stored. The site counts searches per day by area, anonymously, so the region can see which neighborhoods want workshops. That’s a logged exception to The Labs’ rule against activity tracking, and it’s said plainly in the privacy notice.

The list of sessions stays the way in for keyboards and screen readers; the map adds where. It draws itself once when it comes into view, and with reduced motion it’s simply there.
