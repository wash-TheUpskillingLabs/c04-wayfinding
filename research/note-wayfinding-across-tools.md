# Note: wayfinding across tools

*Nov 6, 2026. How the multi-tool reality (Slack, GitHub, Google Workspace, Luma, the OLOS app, agents) bears on this pod's question. Context for Scaffolding and Front Door.*

**Every tool is a place, and switching tools is a threshold.** A newcomer crosses from a Luma invite to Slack to a GitHub issue to a Google Doc to OLOS, and each switch is a chance to get lost.

What this pod would own:
1. **"Where am I?" answerable from any tool**, with the same map in each (pervasive information architecture; see `theory-calm-and-multichannel.md`).
2. **Every message points to one next place.** Alumni: links came from individual trainers, not a central location.
3. **The tool switch is designed, not discovered.** Why you're switching, what to do there first, who to ask. Tool setup is one of the first places open-source newcomers quit (`case-oss-newcomer-barriers.md`).
4. **The same names everywhere.** The six-weeks vs twelve-weeks mismatch in The Labs' own documents shows the cost.
5. **A person, not a bot, at the big crossings.**
6. **Online leads into the room**, and the record carries the room back out.

Split: Front Door owns where the truth lives and how each tool reads from it. Scaffolding owns what you do inside a tool. Wayfinding owns how you know which tool to go to next, and that you're in the right place when you get there.

**A test for the pod:** take one past participant's real path, from first hearing about The Labs to their last contribution, and list every tool they touched in order. Every switch is a threshold.
